# minishell
Minishell project based on the [Stephen Brennan Tutorial](https://brennan.io/2015/01/16/write-a-shell-in-c/). The idea is to start following and understanding the tutorial, and then implementing extra functionality that wasn't included in it. The purpose of it is to go deeper into what goes under the hood when we're using our shell.

# Helpful resources to understand the project
## For C
Even though I have C experience from college, I've found [Dive Into Systems](https://diveintosystems.org/) to be a great book that gently introduces the language. If you want to go deeper, I've used Modern C a bit and have a Hacker's Delight on my read later list.

## Linux Systems Programming
I'm currently using [The Linux Programming Interface: A Linux and UNIX System Programming Handbook](https://www.amazon.com/Linux-Programming-Interface-System-Handbook/dp/1593272200)

# How to run it
## Prerequisites
I believe any distro of Linux will do. I currently use Ubuntu 24.04.5

## Commands
```Bash
Make 
```
The make command will build the binary in bin/ 
To execute it type:
```Bash
./bin/minishell
```

If you want to clean the binary just type:
```Bash
Make clean
```
